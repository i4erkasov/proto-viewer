# Proto Viewer — Help

Просмотр и декодирование protobuf-сообщений в JSON.

## Источники
- **File** — выбрать `.bin`/payload-файл (или перетащить файл в окно).
- **Redis** — достать значение по ключу.

## Декодирование
1. Укажи **Proto root**, **Proto file** и **Message type**.
2. Выбери источник и нажми **Decode**.
3. Результат откроется во вьювере.

## Вьювер
- **Cmd/Ctrl+F** — поиск (повторное нажатие закрывает), **Esc** — закрыть.
- **Cmd/Ctrl+A** — выделить весь текст, **Cmd/Ctrl+C** — копировать выделение
  (если выделения нет — выбранный ключ/значение).
- Свернуть/развернуть узел: клик по треугольнику **▸/▾** слева или по `{ … }` / `[ … ]`.
- Иконки в правом верхнем углу: **Diff** (сравнение), **копировать весь JSON**,
  **сохранить в файл**, **развернуть окно**.

## Settings
- **Enable logs** — показывает панель логов снизу (производительность декода/рендера,
  ошибки). Логи можно сохранить в файл кнопкой-дискетой в шапке панели и прислать
  для диагностики. Долгие операции помечаются `[SLOW]`.

## Diff — сравнение (ранний доступ / демо)
> ⚠️ Функция в **раннем доступе**, будет дорабатываться. Возможны шероховатости.

Сравнение двух proto-сообщений построчно с подсветкой различий.

1. Декодируй первый источник (это сторона **A**).
2. Нажми иконку **Diff** в правом верхнем углу — откроется окно выбора
   **второго источника (B)** с вкладками File/Redis (можно перетащить файл).
3. Нажми **Compare** — откроется окно сравнения **A | B**:
   - различия слева красным (удалено/изменено), справа зелёным (добавлено/изменено);
   - **◀ / ▶** — переход по изменениям;
   - **Expand all / Collapse all** — развернуть/свернуть весь JSON в обеих сторонах;
   - прокрутка и поиск (**Cmd/Ctrl+F**) синхронны для обоих окон.

Ограничения раннего доступа: дифф построчный (поля `map` с разным порядком ключей
могут давать «шум»), нет сводки по количеству изменений.
