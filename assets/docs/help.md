# Proto Viewer — Help

Просмотр и декодирование protobuf-сообщений в JSON.

## Источники
- **File** — выбрать `.bin`/payload-файл (или перетащить файл в окно).
- **Redis** — достать значение по ключу.

## Декодирование
1. Укажи **Proto root**, **Proto file** и **Message type**.
2. Выбери источник и нажми **Decode**.
3. Результат откроется во вьювере.

### Авто-детект типа (Detect)
Если тип неизвестен — нажми **Detect** рядом с полем Message type. Нужен только
**Proto root** (Proto file необязателен: если он пуст, ищем по всем `.proto`
в папке). Приложение переберёт сообщения из proto и подберёт подходящие по байтам,
показав ранжированный список: **✓** — схема объясняет все данные, **~** —
частично (есть нераспознанные поля). У каждого кандидата: число заполненных
полей, объём `unknown` и глубина вложенности. Клик подставляет тип.
Это эвристика (в байтах protobuf нет имени типа), поэтому возможны несколько
вариантов — выбор за тобой.

### Авто-детект кодировки
Обёртки снимаются автоматически — отдельной галки больше нет. Поддерживаются
**gzip, zlib, base64, hex** (в т.ч. вложенные, напр. `base64(gzip(...))`) и
hex с префиксом `0x`. Распознанная цепочка показывается в статусе, например
`Status: OK · base64 → gzip → protobuf`. Усечённые дампы (обрезанный «хвост»)
в режиме RAW показываются до места обрыва с пометкой `… truncated`.

## Вьювер
- **Cmd/Ctrl+F** — поиск (повторное нажатие закрывает), **Esc** — закрыть.
- **Cmd/Ctrl+A** — выделить весь текст, **Cmd/Ctrl+C** — копировать выделение
  (если выделения нет — выбранный ключ/значение).
- Свернуть/развернуть узел: клик по треугольнику **▸/▾** слева или по `{ … }` / `[ … ]`.
- Иконки в правом верхнем углу: **Diff** (сравнение), **копировать весь JSON**,
  **сохранить в файл**, **развернуть окно**.

## Settings
- **Enable logs** — показывает панель логов снизу (производительность декода/рендера,
  ошибки). Логи можно сохранить в файл кнопкой-дискетой в шапке панели и прислать
  для диагностики. Долгие операции помечаются `[SLOW]`.

## Diff — сравнение (ранний доступ / демо)
> ⚠️ Функция в **раннем доступе**, будет дорабатываться. Возможны шероховатости.

Сравнение двух proto-сообщений построчно с подсветкой различий.

1. Декодируй первый источник (это сторона **A**).
2. Нажми иконку **Diff** в правом верхнем углу — откроется окно выбора
   **второго источника (B)** с вкладками File/Redis (можно перетащить файл).
3. Нажми **Compare** — откроется окно сравнения **A | B**:
   - различия слева красным (удалено/изменено), справа зелёным (добавлено/изменено);
   - **◀ / ▶** (сверху) — переход по изменениям;
   - **сводка** внизу окна: `~3  +2  −1` — изменено / добавлено / удалено;
     при навигации добавляется позиция `[2/6]`;
   - **Normalize** — сортировка ключей (вкл. по умолчанию): снимает «шум» от
     разного порядка ключей в `map`; выключи, чтобы вернуть proto-порядок полей;
   - кнопка-тумблер **развернуть/свернуть** всё (иконка меняется по состоянию);
   - прокрутка и поиск (**Cmd/Ctrl+F**) синхронны для обоих окон.

Ограничения раннего доступа: дифф построчный (структурное сравнение, нечувствительное
к порядку, — в планах).
