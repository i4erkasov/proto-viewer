# Proto Viewer — Help

Просмотр и декодирование protobuf-сообщений в JSON.

## Источники
- **File** — выбрать `.bin`/payload-файл (или drag&drop).
- **Redis** — достать значение по ключу.

## Декодирование
1. Укажи **Proto root**, **Proto file** и **Message type**.
2. Выбери источник и нажми **Decode**.
3. Результат откроется во вьювере (поиск, фолдинг, выделение, копирование).

## Вьювер
- **Cmd/Ctrl+F** — поиск (повторное нажатие закрывает), **Esc** — закрыть.
- **Cmd/Ctrl+A** — выделить весь текст, **Cmd/Ctrl+C** — копировать выделение.
- Клик по `{ … }` / `[ … ]` — свернуть/развернуть узел.
- Иконки вверху справа: копировать весь JSON, сохранить в файл, развернуть окно.

## Settings
- **Enable logs** — включает панель логов снизу (производительность декода/рендера).
  Логи можно сохранить в файл кнопкой-дискетой в шапке панели.

## Diff (ранний доступ / демо)
> ⚠️ Функция в **раннем доступе** — это демонстрационная версия, она будет
> дорабатываться. Возможны шероховатости.

Сравнение двух proto-сообщений построчно с подсветкой различий.

- Включается через меню **Mode → Diff** (обратно — **Mode → Viewer**).
- Настройки **Proto root / file / Message type** — общие сверху.
- Окно делится пополам: слева сторона **A**, справа **B**; в каждой свой выбор
  источника (File/Redis).
- **Compare** — декодирует обе стороны и показывает различия:
  слева красным (удалено/изменено), справа зелёным (добавлено/изменено).
- **◀ / ▶** — переход по различиям, **Expand/Collapse all** — развернуть/свернуть
  весь JSON в обеих сторонах, **Hide sources** — скрыть выбор источника.
- Прокрутка и поиск (**Cmd/Ctrl+F**) работают синхронно для обоих окон.

Известные ограничения раннего доступа: дифф построчный (поля `map` с разным
порядком могут давать «шум»), нет сводки по количеству изменений.
