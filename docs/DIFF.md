# Режим Diff (сравнение двух proto)

> ⚠️ **Ранний доступ / демо.** Функция работоспособна, но это демонстрационная
> версия — она будет дорабатываться (сводка изменений, нормализация ключей,
> сглаживание UX). Возможны шероховатости.

Сравнение двух декодированных protobuf-сообщений построчно, с подсветкой
различий. Включается через меню **Mode → Diff** (обратно — **Mode → Viewer**).

## UI
- Верхние настройки **Proto root / Proto file / Message type** — **общие** для
  обеих сторон.
- Ниже — две половины (`HSplit`, делитель тянется мышью). Каждая половина — это
  переиспользуемый компонент `sidePanel`: свои вкладки **File/Redis** (выбор
  источника) + свой **JSON-вьювер** (со всей инфраструктурой: поиск, фолдинг,
  выделение, мультибайт).
- Панель управления над сплитом:
  - **Compare** — декодирует **обе** стороны из их текущих источников и считает
    дифф (одна общая кнопка вместо двух Decode).
  - **Expand all / Collapse all** — разворачивают/сворачивают весь JSON сразу в
    обеих сторонах.
  - **Hide / Show sources** — одной кнопкой сворачивает области выбора источника
    в обеих половинах (больше места вьюверам).
  - **◀ / ▶** + счётчик (`n/total`) — навигация по участкам различий.

## Подсветка
- Слева (A) — различающиеся строки **красным** (удалено/изменено).
- Справа (B) — **зелёным** (добавлено/изменено).
- Общие строки — без фона. Выделение текста и подсветка поиска перекрывают
  фон диффа.

## Поведение
- **Синхронная прокрутка**: прокрутка любой стороны (колесо/драг/навигация по
  поиску) двигает вторую на то же смещение — одна прокрутка на оба окна.
- **Навигация ◀/▶**: прыгает к началу следующего/предыдущего участка различий,
  **разворачивая** свёрнутые узлы по пути и центрируя обе панели.
- **Поиск (Cmd/Ctrl+F)** в Diff открывает поле поиска в **обеих** сторонах
  (поле прижато к правому краю; чекбокс «Only matches» в Diff скрыт).
  **Esc** закрывает поиск в обеих.
- При смене режима подсветка и состояние сохраняются у каждого вьювера.

## Алгоритм (`internal/ui/diff.go`)
- `computeLineDiff(aLines, bLines)` — построчный **LCS** (DP на int32):
  возвращает множества различающихся строк A/B и упорядоченные **хунки**
  (старты участков различий с привязкой строк A↔B для навигации).
- Дифф считается по тексту в текущем порядке полей (для одного типа сообщения
  порядок одинаковый, различия настоящие).
- Для огромных входов (LCS-таблица > ~4M ячеек) — дешёвый **fallback** по
  множеству строк (без учёта порядка/дублей), хунки приблизительные.

## Реализация
- `internal/ui/sidepanel.go` — компонент стороны (`sidePanel`): источник +
  вьювер + декод (`Decode()`), методы `SetSourceVisible/SetSearchVisible/...`,
  колбэк `onDecoded` для пересчёта диффа.
- `internal/ui/layout.go` — сборка diff-режима: общие настройки, `HSplit`,
  панель управления, `applyDiff` (пересчёт+покраска), навигация, синхроскролл,
  mode-aware Cmd+F/Esc, переключатель **Mode**.
- `internal/ui/widgets/jsonviewer` — добавлено:
  `SetDiffLines(map[int]color.Color)` (фон строк), `ScrollToSourceLine` (с
  разворотом свёрнутого), `OnScrolled`/`SetScrollOffset` (синхроскролл),
  `SetOnlyMatchesVisible`.

## Известные ограничения / возможные улучшения
- Дифф **построчный**; `map`-поля с разным порядком ключей могут давать «шум» —
  можно добавить нормализацию (сортировку ключей) тумблером.
- Нет сводки «N изменено / добавлено / удалено».
- Стороны декодируются одним типом сообщения (из общих настроек).
